# 计算机网络基础
## HTTP 请求与响应
客户端发出请求，包含方法、路径、请求头和可选请求体；服务端返回状态码、响应头和响应体。GET 通常读取资源，POST 通常提交数据。HTTP 无状态意味着协议本身不自动记住两次请求的业务关系；应用可以通过 Cookie、会话标识等管理状态。
## TCP 与 UDP
TCP 提供面向连接的可靠、有序字节流，通过确认、重传和流量控制等机制传输数据。UDP 提供数据报服务，不保证交付和顺序，应用可以自行实现所需机制。不能简单地说所有实时应用都只使用 UDP。
## DNS 与 HTTPS
DNS 把域名解析为地址等记录。HTTPS 是通过 TLS 保护的 HTTP，提供传输加密、完整性保护和服务器身份验证。HTTPS 不代表服务端内容一定可信，也不能替代应用层权限控制。
