# Python 编程基础
## 列表与元组
列表 list 是可变序列，可以添加、删除和替换元素；元组 tuple 是不可变序列，不能替换它直接引用的元素。但元组内部若包含列表，该列表本身仍可以修改。选择时先看数据是否需要修改，不应把元组不可变理解成其所有嵌套对象都不可变。
## 函数参数与可变对象
Python 的参数绑定到传入对象。函数内部修改列表内容，调用方可以观察到变化；把参数重新赋值为另一个对象，并不会重新绑定调用方的变量。避免把空列表作为需要每次独立使用的默认参数，可使用 None，再在函数内部创建新列表。
## 异步基础
async def 定义协程函数，调用后得到协程对象；await 等待可等待对象完成。异步适合等待网络和文件等 I/O。同步阻塞操作直接放入协程仍会阻塞事件循环，可以通过 asyncio.to_thread 运行同步 I/O。async 不意味着代码自动并行，也不会自动加速 CPU 密集计算。
